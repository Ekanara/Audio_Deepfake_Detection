# Project: Audio Deepfake Detection

## Environment
- Always use WSL (Ubuntu) for training and inference commands
- Activate conda env first: `conda activate deepfake_detection`
- Command pattern: `wsl -d Ubuntu -- bash -lc 'conda activate deepfake_detection && cd /mnt/d/Github/Audio_Deepfake_Detection && <command>'`
- Repo path in WSL: `/mnt/d/Github/Audio_Deepfake_Detection`
